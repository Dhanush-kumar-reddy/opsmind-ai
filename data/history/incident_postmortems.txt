Incident: INC-2026-0401
Service: Auth API
Severity: High

Summary
Users experienced intermittent login failures
after a Redis replica synchronization issue.

Observed Symptoms
- Login requests timing out
- Session creation failures
- Elevated API retry count
- Increased authentication latency

Root Cause
Redis replication synchronization failed
during high traffic load causing stale
session reads and connection instability.

Resolution
- Restarted Redis replicas
- Cleared stale authentication sessions
- Increased Redis connection pool size
- Enabled additional monitoring alerts
